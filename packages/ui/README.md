# @seapass/ui

Design system compartilhado: componentes React genéricos (botões, inputs, cards, modais) baseados em Radix UI + Tailwind, usados tanto pelo site público quanto pelos painéis de organizador/admin dentro de `apps/web`.

Pacote deliberadamente pequeno na v1 — só é promovido para cá um componente que já se repete em pelo menos duas features de `apps/web/src/features`. Evita abstração prematura de design system antes de haver reuso real.
